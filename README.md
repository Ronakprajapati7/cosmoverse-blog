# 🌌 CosmoVerse Blog

> An immersive deep space & astronomy blogging website built with **100% Pure HTML5, CSS3, and Vanilla JavaScript**.

No Node.js, no npm dependencies, no build tools, and no frameworks required. It runs instantly by double-clicking `index.html` or deploying directly to **GitHub Pages**.

---

## ✨ Features

- **🚀 100% Static & Standalone**: Zero dependencies. Works natively in any modern web browser right from the local file system (`file://`) or hosted on GitHub Pages.
- **💾 Client-side Persistence (`localStorage`)**:
  - Pre-seeded with 4 cosmic exploration articles and community comments.
  - Create, publish, like, and comment on articles with instant browser storage.
  - Delete transmissions at any time.
- **🔍 Real-time Search & Filter**: Instant live filtering by celestial domains (Deep Space, Missions, Astrophysics, Exoplanets, Space Tech) and keyword search.
- **🌌 Cosmic Aesthetics**: Modern glassmorphism UI with glow effects, responsive card grids, and high-definition telescope photography.
- **📱 Fully Responsive**: Tailored layout for mobile, tablet, and desktop screens.

## 🚀 How to Run Locally

Simply double-click `index.html` in your file explorer, or right-click and choose **Open with > Chrome / Edge / Firefox**.

---

## 🌐 Deploy to GitHub Pages (1-Click Hosting)

1. Push this repository to GitHub.
2. Go to your repository **Settings** > **Pages** (under the "Code and automation" section).
3. Under **Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**.
5. Your live blog will be available at `https://ronakprajapati7.github.io/cosmoverse-blog/`!
